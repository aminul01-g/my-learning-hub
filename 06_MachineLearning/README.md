# 🧪 Core Machine Learning: Algorithms & Modeling

This module implements classical machine learning algorithms using **Scikit-Learn**. It covers supervised (Regression & Classification) and unsupervised (Clustering) learning through real-world datasets.

## 📁 Key Implementations

- **[`Predictive-Modeling-of-Ames-Housing-Data`](./Predictive-Modeling-of-Ames-Housing-Data)**: Advanced regression techniques to predict house prices.
- **[`Diabetes-Detection-System`](./Diabetes-Detection-System)**: Binary classification using patient health metrics.
- **[`Clustering_Iris_Dataset`](./Clustering_Iris_Dataset)**: Unsupervised learning to identify flower species without labels.
- **[`ml.ipynb`](./ml.ipynb)**: A comprehensive scratchpad for feature engineering, scaling, and hyperparameter tuning.

## 📊 Dataset Usage
- **`titanic.csv`**: Used for survival prediction, exploring feature importance and handling missing values.

## 🗝️ Core Concepts Covered

- **Regression**: Linear and Polynomial models for continuous target prediction.
- **Classification**: Logistic Regression, Random Forests, and SVMs.
- **Clustering**: K-Means and Hierarchical clustering.
- **Evaluation**: Accuracy, Precision-Recall, F1-Score, and Mean Squared Error.
- **Validation**: Train-test splitting and k-Fold Cross-validation.
