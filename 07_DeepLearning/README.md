# 🧠 Deep Learning: Advanced Architectures

This directory contains implementations of advanced neural network architectures using **TensorFlow** and **Keras**, covering Computer Vision (CV), Natural Language Processing (NLP), and Sequence Modeling.

## 📁 Project Portfolio

### 👁️ Computer Vision
- **[`Digit_Classification-acc-98.43`](./Digit_Classification-acc-98.43)**: High-accuracy digit recognition on the MNIST dataset.
- **[`fashion-mnist-nn-vs-cnn`](./fashion-mnist-nn-vs-cnn)**: A comparative study between Standard Neural Networks and Convolutional Neural Networks (CNNs).
- **[`clothing-classifier`](./clothing-classifier)**: Multi-class image classification for apparel.

### ✍️ Natural Language Processing (NLP)
- **[`IMDB-Sentiment-Analysis`](./IMDB-Sentiment-Analysis)**: Binary sentiment classification on movie reviews.
- **[`Question_Answer_prediction-RNN`](./Question_Answer_prediction-RNN)**: Simple Q&A system using Recurrent Neural Networks (RNNs).
- **[`Next_Word_Prediction-LSTM`](./Next_Word_Prediction-LSTM)**: Generative sequence modeling using Long Short-Term Memory (LSTM) networks.

### 🧪 Foundational Lab
- **[`dl.ipynb`](./dl.ipynb)**: A playground notebook for experimental deep learning layers and activation functions.

## 🛠️ Getting Started

### Installation
Ensure you have the core Deep Learning stack:
```bash
pip install tensorflow keras matplotlib numpy scikit-learn
```

## 🗝️ Core Concepts Covered

- **CNNs**: Pooling, Striding, and Feature Maps for Image Data.
- **RNNs & LSTMs**: Managing vanishing gradients and long-term dependencies in text.
- **Word Embeddings**: Representing language in high-dimensional vector spaces.
- **Evaluation**: Accuracy curves, Confusion Matrices, and Sentiment Metrics.
